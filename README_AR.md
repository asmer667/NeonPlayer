# Neon Player — مشروع Android

مشغل فيديو محلي تجريبي قابل للتطوير، بواجهة عربية مستوحاة من مرجع التصميم المرفق.

## فتح المشروع
- فك ضغط الأرشيف.
- افتح مجلد `NeonPlayer_Final_Project` في Android Studio.
- استخدم JDK 17.
- نفّذ Gradle Sync، ثم `:app:assembleDebug`.

## الوظائف الموجودة
- واجهة رئيسية بطابع زجاجي داكن مع تدرجات نيون.
- شريط علوي وأزرار إضافة وإعدادات.
- شريط تنقل سفلي تفاعلي.
- استيراد ملفات فيديو من منتقي Android.
- عرض الملفات المستوردة في المكتبة.
- تشغيل الفيديو عبر AndroidX Media3 ExoPlayer مع أدوات التحكم الأصلية.
- إضافة/إزالة عناصر المفضلة وعرضها.
- صفحات أولية للأقسام والموسيقى والتاريخ والإعدادات.
- تبديل إعدادات مظهرية داخل الشاشة.

## ملاحظات مهمة
هذه نسخة تأسيسية عملية وليست نسخة نهائية مطابقة 100% للصورة. لا تتضمن بعد:
- استخراج صور مصغرة فعلية لكل فيديو.
- حفظ المكتبة والمفضلة وسجل المشاهدة بعد إغلاق التطبيق (Room/DataStore).
- فهرسة مجلدات الهاتف تلقائياً.
- تفاصيل مواسم وحلقات الأنمي والمسلسلات.
- مشغل مخصص بالكامل بأزرار السرعة والترجمة والإيماءات.
- كل شاشات لوحة التحكم التفصيلية الظاهرة في الصورة.

التطبيق يستخدم Storage Access Framework لاختيار الفيديو دون طلب صلاحية تخزين واسعة.
